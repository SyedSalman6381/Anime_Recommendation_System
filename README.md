# Anime_Recommendation_System
# 🎌 Anime Recommendation System

An intelligent anime recommendation system built with Python that uses live anime data from the AniList GraphQL API to help users discover anime based on their interests and preferences.

The system combines recommendation techniques, Natural Language Processing (NLP), and ranking algorithms to identify relevant anime using genres, tags, ratings, popularity, and related titles. It fetches up-to-date information directly from an external API rather than relying entirely on a fixed anime dataset.

## Key Features
- **Live API Integration:** Retrieves anime information from the AniList GraphQL API.
- **Personalized Recommendations:** Suggests anime based on user preferences.
- **Genre-Based Filtering:** Recommends titles matching selected genres.
- **Rating and Episode Filters:** Filters anime according to minimum ratings and episode limits.
- **Related Anime Discovery:** Uses related titles and anime metadata to expand recommendations.
- **NLP-Based Matching:** Uses anime descriptions, tags, and metadata to improve relevance.
- **Recommendation Ranking:** Ranks candidate anime according to their relevance to the selected title and preferences.

## Tech Stack
- Python
- AniList GraphQL API
- Natural Language Processing (NLP)
- Machine Learning and recommendation techniques
- Requests
